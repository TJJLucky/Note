WASM 教学索引

本目录用于保存关于 WebAssembly（Wasm）的系统化、专业化教学内容与示例代码。文档按专题分为多个章节，后续新的教学内容将持续追加到此处。

章节列表：

- 01 - 概览与目标: 01_core_concepts.md
- 02 - 内部机制: 02_internal_mechanisms.md
- 03 - 工具链与编译流程: 03_toolchain_and_flow.md
- 04 - 性能与安全分析: 04_performance_and_security.md
- 05 - 示例与实战（含 Rust/C→Wasm 示例）: 05_examples.md
- 06 - 进阶资源与学习路线: 06_resources.md

使用说明：
- 我会把每次教学（包括后续更深入专题、练习、示例）都写成独立或追加的 Markdown 文件放在本目录。
- 你可以指定要我现在深入讲解的某一章节，我会把详尽内容追加到对应文件并更新索引。
