第 1 章 — 核心概念（专业详解）

1. 概述
- WebAssembly（Wasm）是一种可移植的二进制指令格式与运行时抽象，设计目标是安全、可移植、近原生性能的沙箱执行环境。它不是一门语言，而是一个低级、与平台无关的编译目标。

2. 模块（Module）
- 模块是 Wasm 的基本封装单位，包含：类型段、函数段、导入/导出、内存/表定义、数据/元素段、全局变量、起始函数（start）与自定义段。
- 导入（import）：模块可以声明从外部宿主导入函数、内存、表或全局变量。
- 导出（export）：模块显式导出函数/内存/表/全局变量，供宿主或其他模块调用。

3. 线性内存（Linear Memory）
- Wasm 的内存为线性内存：单段、连续的字节数组表示为一个或多个 `pages`（每 page 通常为 64 KiB）。
- 通过导出或导入 `memory`，宿主（如 JS）可将 ArrayBuffer 直接映射到模块内存以实现零拷贝交互。
- 边界检测：Wasm 在运行时不自动插入内存越界检查指令，但加载器/运行时会确保模块不会绕过内存安全，越界访问会被捕获并触发错误。

4. 表（Table）与间接调用
- `table` 存放函数引用（`funcref`），用于间接函数调用（类似 C 的函数指针表），支持动态链接与多态调用路径。

5. 值与类型系统
- 基本数值类型：`i32`, `i64`, `f32`, `f64`。
- 引用类型扩展（proposal）：`funcref`, `externref` 等；未来通过 GC proposal 将支持复杂语言运行时的托管对象。

6. 控制流与栈机模型
- Wasm 指令为基于栈的中间指令集，函数调用与局部变量用显式局部和操作数栈来处理，这大幅简化了验证与 JIT 编译。

7. 导入/导出与宿主交互
- 常见模式：宿主提供环境（`env`）模块里的一组函数（如内存分配、IO、时间等），模块导入并调用这些函数；模块把核心功能导出供宿主调用。

8. 文本格式（.wat）与二进制格式（.wasm）
- `.wat`：用于阅读与调试的 s-expression 文本格式。
- `.wasm`：紧凑二进制格式，用于网络传输与快速解析。

9. 小结
- Wasm 关注：安全（沙箱）、可移植性（多运行时）、性能（紧凑二进制、静态类型）、并构成多语言互操作与边缘/嵌入式部署的低层基石。
