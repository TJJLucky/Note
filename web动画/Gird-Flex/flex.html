flex-grow / flex-shrink / flex-basis 详解

flex-basis：初始大小（基准值）

flex-basis 指定项目的初始基准宽度，即在分配剩余空间之前项目的大小。 类似（但不完全等于）width，但优先级更高。

  • flex-basis: 200px → 项目初始宽度 200px
  • flex-basis: auto（默认值）→ 按自身 width 或内容宽度计算
  • flex-basis: 0 → 从 0 开始，完全依赖 grow/shrink 分配

flex-grow：扩展比例（如何瓜分剩余空间）

当所有项目的 flex-basis 之和 小于 容器宽度时， 会有"剩余空间"。flex-grow 决定每个项目如何按比例拿走这些剩余空间。

  • flex-grow: 0（默认值）→ 不参与分配，保持 flex-basis 的宽度
  • flex-grow: 1 → 参与平均分配（所有项目都 1，则平分剩余空间）
  • flex-grow: 2 → 拿的剩余空间是 grow:1 项目的 2 倍

计算公式：项目宽度 = flex-basis + 剩余空间 × (自身grow / 所有项目grow之和)

flex-shrink：收缩比例（空间不足时如何压缩）

当所有项目的 flex-basis 之和 大于 容器宽度时， 会产生"不足空间"。flex-shrink 决定每个项目按什么权重被压缩。

  • flex-shrink: 0 → 禁止压缩，最小宽度为 flex-basis（即使溢出也不缩）
  • flex-shrink: 1（默认值）→ 按权重等比压缩
  • flex-shrink: 2 → 压缩速度是 shrink:1 项目的 2 倍

计算公式：压缩量 = 不足空间 × (自身shrink × flex-basis / 加权总和)

flex 简写全家桶

写法 等价于 说明
flex: 1 1 1 0% 均分剩余空间，常用于"等高自适应"列
flex: auto 1 1 auto 可伸可缩，基准为自身 width
flex: 0 0 200px — 固定宽度，既不伸也不缩
flex: 1 0 200px — 基准 200px，可伸但不缩（常用于"最小宽度"保护）
flex: 0 1 200px — 基准 200px，可缩但不伸
