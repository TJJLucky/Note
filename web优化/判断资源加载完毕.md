判断“资源加载是否已经完成”要先区分你说的是哪一类资源；在浏览器里最常用的 2 种判断方式如下。

  

**1) 判断整个页面资源是否加载完成（图片/****CSS****/字体等都算）**

- `DOMContentLoaded`：HTML 解析完、DOM 可用，但图片/字体/部分资源可能还没好。
    
- `window.load`：页面所有子资源（图片、样式、字体文件等）都加载完才触发。
    
      
    

示例（最简单、最可靠）：

```JavaScript
document.addEventListener('DOMContentLoaded', () => {
  console.log('DOM ready');
});

window.addEventListener('load', () => {
  console.log('All resources loaded');
});
```

  

如果你只是想“判断现在是不是已经加载完了”，可以看：

```JavaScript
if (document.readyState === 'complete') {
  // 等同于 load 已发生或即将发生
}
```

  

**2) 判断“某个资源/某个请求”是否完成（更精确）**

- `fetch`：用 Promise 的 `then/await` 就是“完成”。
    

```JavaScript
async function loadData() {
  const res = await fetch('/some.json');
  const data = await res.json();
  console.log('fetch done', data);
}
```

  

- 字体（Font Loading API）：判断字体是否加载成功
    

```JavaScript
await document.fonts.ready;              // 所有字体就绪
const ok = await document.fonts.check('16px "Work Sans"'); // 某字体是否可用
```

  

- A) 页面所有资源都完成（用 `window.load`）
    
- B) 你自己发起的某个请求完成（用 `await fetch(...)`）
    
- C) 字体预加载/字体是否可用（用 `document.fonts.ready/check`）
