# 图片优化

## 1. 响应式图片

### 使用 `srcset` 和 `sizes` 属性

```html
<img 
  src="image-400w.jpg" 
  srcset="
    image-400w.jpg 400w,
    image-800w.jpg 800w,
    image-1200w.jpg 1200w
  " 
  sizes="(max-width: 600px) 100vw, (max-width: 1200px) 50vw, 33vw"
  alt="响应式图片"
/>
```

### 使用 `<picture>` 元素

```html
<picture>
  <source media="(max-width: 600px)" srcset="mobile.jpg">
  <source media="(max-width: 1200px)" srcset="tablet.jpg">
  <img src="desktop.jpg" alt="桌面端图片">
</picture>
```

## 2. 为不同设备指定图像尺寸

| 设备类型 | 推荐宽度 | 使用场景 |
|---------|---------|---------|
| 手机 | 320px - 640px | 移动端视口 |
| 平板 | 768px - 1024px | 平板设备 |
| 桌面 | 1280px - 1920px | 标准桌面 |
| 高清屏 | 2x 像素密度 | Retina 显示屏 |

### 像素密度匹配

```html
<img 
  src="image-400w.jpg"
  srcset="
    image-400w.jpg 1x,
    image-800w.jpg 2x
  " 
  alt="适配高密度屏幕"
/>
```

## 3. 防止布局偏移 (CLS)

### 固定宽高比

```html
<!-- 使用 aspect-ratio 属性 -->
<img src="photo.jpg" alt="照片" style="aspect-ratio: 16/9; width: 100%;">

<!-- 使用 CSS -->
<style>
  .image-container {
    aspect-ratio: 16 / 9;
    width: 100%;
    background-color: #f0f0f0; /* 占位颜色 */
  }
  .image-container img {
    width: 100%;
    height: 100%;
    object-fit: cover;
  }
</style>
<div class="image-container">
  <img src="photo.jpg" alt="照片">
</div>
```

### 预留空间

```html
<img 
  src="photo.jpg" 
  width="800" 
  height="450" 
  alt="照片"
  style="max-width: 100%; height: auto;"
>
```

## 4. 懒加载

### 原生懒加载

```html
<img src="photo.jpg" loading="lazy" alt="懒加载图片">

<!-- 首屏图片不使用懒加载 -->
<img src="hero.jpg" loading="eager" alt="首屏图片">
```

### JavaScript 懒加载 (Intersection Observer)

```javascript
const lazyImages = document.querySelectorAll('img[data-src]');

const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const img = entry.target;
      img.src = img.dataset.src;
      img.removeAttribute('data-src');
      observer.unobserve(img);
    }
  });
});

lazyImages.forEach(img => observer.observe(img));
```

```html
<img data-src="photo.jpg" src="placeholder.jpg" alt="懒加载图片">
```

### CSS 背景图懒加载

```javascript
const lazyBackgrounds = document.querySelectorAll('[data-bg]');

const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      const element = entry.target;
      element.style.backgroundImage = `url(${element.dataset.bg})`;
      element.removeAttribute('data-bg');
      observer.unobserve(element);
    }
  });
}, { rootMargin: '50px' }); // 提前 50px 开始加载

lazyBackgrounds.forEach(el => observer.observe(el));
```
